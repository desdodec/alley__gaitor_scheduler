# Alley Gaitor public media assets

Files in this folder are copied directly into the built site and are available under `/assets/...` on Netlify.

Suggested structure:

- `images/` — project photos, artwork examples, explanatory diagrams
- `audio/` — short bicycle-walk recordings, DTMF examples, processed sound examples
- `video/` — short demonstrations or visual walkthroughs

Recommended web-friendly formats:

- Images: `.webp`, `.jpg`, `.png`, `.svg`
- Audio: `.mp3`, `.m4a`, `.wav` (prefer compressed formats for public playback where possible)
- Video: `.mp4` (H.264/AAC is the safest general web choice)

Use short descriptive lowercase filenames with hyphens, for example:

- `images/bicycle-walk-example-01.webp`
- `audio/raw-bicycle-recording-01.mp3`
- `audio/processed-click-pattern-01.mp3`
- `video/how-the-session-works.mp4`

Do not upload participant-identifying material, private recordings, personal data, or anything that should not be public. This repository is public.

Once example media is uploaded, the public first-timer homepage can reference files directly, e.g. `/assets/audio/raw-bicycle-recording-01.mp3`.
